# GlucoseInsight - AI Health Assistant


GlucoseInsight - AI Health Assistant is an advanced, AI-powered healthcare platform designed to provide real-time diabetes support, analysis, and insights.Unlike traditional prediction or diagnosis tools, this integrates Generative AI (Gemini) to deliver interactive, conversational, and context-aware responses.It also has a personal AI health companion. Whether you want to understand symptoms, medication dosage, meal impact, health risks, or side effects, the personal assistant provides accurate and instant answers tailored to your queries.

## Tech Used:
- Python (3.12 or higher)
- Streamlit
- React JS
- Gemini AI API

## Modules:
- Home Page : Clean landing page with project overview and navigation.
- Ask Query : AI-powered health assistant using Google Gemini for real-time, conversational medical insights.
- Diagnosis : User inputs clinical data → ML model predicts diabetes risk with interpretability.
- Result Visualization : Interactive charts and visual feedback to help users understand prediction outcomes.
- Knowledge Center : Structured information about diabetes management.
